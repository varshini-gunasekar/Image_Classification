# Image Classification Using a Pretrained Model

## Project Overview
This project classifies images using a pretrained MobileNetV2 deep learning model trained on the ImageNet dataset.

## Technologies Used
- Python
- TensorFlow
- MobileNetV2
- Pillow (PIL)
- NumPy

## Features
- Accepts an image file path from the user.
- Preprocesses the image for model prediction.
- Predicts the top 3 possible image categories.
- Displays the predicted labels and confidence scores.

## How to Run
1. Install the required libraries:
   `python -m pip install tensorflow pillow numpy`
2. Run the program:
   `python image_classifier.py`
3. Enter the full path of an image when prompted.
4. View the classification results in the terminal.

## Model
MobileNetV2 pretrained on ImageNet.
